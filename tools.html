生命保険の価値を
最大化する試算ツール

生命保険ツール ディスカッションシート トレーニング 基本情報入力

基幹シミュレーション

決算書と自社株の情報から、生命保険の活用価値を本格的に試算する5本です。

STOCK
Opus.1

自社株×生命保険

生命保険の活用による損金創出が、自社株評価にどう影響するかを試算します。

ツールを使う → LIABILITY
Opus.2

将来負債×生命保険

退職金や事業承継資金など将来必ず発生する負債に、生命保険でどう備えられるかを見える化します。

ツールを使う → TREASURY
Opus.3

金庫株×生命保険

生命保険を原資とした金庫株活用の資金効率を、給与で負担する場合と比較します。

ツールを使う → RETIREMENT
Opus.4

退職金×生命保険

退職金を給与化する場合と生命保険を活用して一括支給する場合の、法人・個人トータルの税務メリットを比較します。

ツールを使う → TAX-FREE
Opus.5

非課税×生命保険

生命保険料控除や相続税・弔慰金の非課税枠を整理し、控除枠・非課税枠の使い残しがないかを試算します。

ツールを使う →

財務・資金繰りに活かす

損金・出口・緊急資金など、保険を財務戦略の道具として使うツールです。

FUNDING
Opus.6

原資創出モデル

役員報酬や各種経費の適正化により、無理なく生命保険料の原資となるキャッシュフローを積み上げて試算します。

ツールを使う → REDUCTION
Opus.7

減額充当モデル

既契約の保険金額を減額し、その解約返戻金を新契約の原資に充てることで生まれる法人税への影響を試算します。

ツールを使う → YEAREND
Opus.8

決算対策インパクト

決算前の保険加入が納税額と手元資金に与える影響を、加入する場合・しない場合で比較します。

ツールを使う → SMOOTH
Opus.9

利益平準化シミュレーション

好況年に保険料で利益を抑え、不況年に解約返戻金で埋める「利益のならし」効果を折れ線で示します。

ツールを使う → LIQUIDITY
Opus.10

契約者貸付×緊急資金

解約せず・審査なしで返戻金の約9割を借りられる契約者貸付を、緊急運転資金の備えとして見える化します。

ツールを使う →

経営リスクに備える

社長・キーマンの万一や就業不能に対して、根拠のある保障額を導くツールです。

CONTINUITY
Opus.11

事業継続資金×生命保険

社長に万一があった時に会社が必要とする資金と、現預金・既契約保障でまかなえる額を1本の棒で比較し、死亡保障をいくらにするかの根拠を作ります。

ツールを使う → PENSION
Opus.12

遺族年金ギャップ×生命保険

万一の際に遺族が受け取る公的年金を概算し、生活費との差額から民間保障の必要額を計算します。

ツールを使う → CASHFLOW
Opus.13

就業不能×資金繰り

社長が生存しているものの働けない場合の月次資金繰りを試算し、何ヶ月目にいくら不足するかを見える化します。

ツールを使う → LOAN
Opus.14

借入残高×保障推移

年々減っていく借入残高と保障額の推移を重ね、当初に必要な保障と10年後に必要な保障を分けて設計します。

ツールを使う → GUARANTEE
Opus.15

連帯保証×生命保険

社長個人が連帯保証している債務と、遺族がすぐに使える資産・保障のギャップを見える化します。

ツールを使う → KEYMAN
Opus.16

キーマン保障×生命保険

経営幹部・キーパーソンを失った場合の利益への影響を年次で積み上げ、必要保障額の目安を計算します。

ツールを使う →

入り方・持ち方を比較する

積立・借入・個人契約・共済などとの比較で、保険の合理性を確認するツールです。

SQUARE
Opus.17

積立vs保険〈四角形と三角形〉

銀行積立は目標額まで時間がかかる三角形、保険は初日から満額の四角形。時間を買うという保険の本質を1枚で示します。

ツールを使う → PREPARE
Opus.18

借入準備vs保険準備

退職金などの将来資金を「その時に借りる」場合と「保険で準備する」場合の総コストを比較します。

ツールを使う → CONTRACT
Opus.19

個人契約vs法人契約

同じ保障を個人契約で持つ場合(報酬を増やして払う)と法人契約で持つ場合の実質負担を比較します。

ツールを使う → TIMING
Opus.20

加入タイミング比較

今日加入する場合と5年後に加入する場合の総支払保険料と無保障期間を比較します。

ツールを使う → RETURN
Opus.21

実質返戻率シミュレーター

支払保険料と解約返戻金の単純返戻率に、損金算入による税軽減効果を織り込んだ実質返戻率を比較します。

ツールを使う → MUTUAL
Opus.22

経営セーフティ共済vs生命保険

全額損金の経営セーフティ共済(上限800万円)と生命保険の役割の違いを整理し、正しい併用を設計します。

ツールを使う →

退職金・福利厚生

役員退職金の設計と、従業員の退職金・弔慰金の備えを作るツールです。

PROPER
Opus.23

適正退職金計算機

功績倍率法による適正退職金と弔慰金・死亡退職金の非課税枠を、入力4項目で即座に計算します。

ツールを使う → LIFETIME
Opus.24

役員報酬vs退職金

同じ金額を毎月の報酬で受け取る場合と退職金で受け取る場合の手取りを比較し、生涯手取りの最大化を設計します。

ツールを使う → EXIT
Opus.25

退職金出口シミュレーター

解約返戻金の雑収入を役員退職金の損金でぶつける出口設計を、ウォーターフォールで見える化します。

ツールを使う → WELFARE
Opus.26

従業員退職金×福利厚生プラン

従業員退職金の要準備総額に対する養老保険(ハーフタックス)での積立進捗と税効果を見える化します。

ツールを使う → GROUP
Opus.27

弔慰金規程×総合福祉団体定期

弔慰金規程から必要保障額を計算し、全員加入の総合福祉団体定期保険で備える設計を示します。

ツールを使う →

承継・相続対策

自社株の承継と相続の資金問題に、保険で答えを出すツールです。

TAXFUND
Opus.28

納税資金×生命保険

社長個人の財産構成から相続税を概算し、すぐに使える金融資産で納税できるかのギャップを確認します。

ツールを使う → DIVISION
Opus.29

代償分割×生命保険

自社株を後継者に集中させる際に他の相続人へ支払う代償金を計算し、保険で準備する設計を示します。

ツールを使う → GIFT
Opus.30

保険料贈与プラン

暦年贈与した資金を保険料に変える定番プランで、現金のまま相続する場合との手残りを比較します。

ツールを使う →
